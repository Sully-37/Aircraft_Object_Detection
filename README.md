## Abstract: ##

This notebook presents a pipeline for bounding box regression on the FGVC-Aircraft dataset using PyTorch and Hugging Face datasets. I begin by exploring the dataset, analyzing class distributions, and preparing image data alongside their annotated bounding boxes. A custom PyTorch Dataset class processes and normalizes images and bounding box coordinates for training.  employ a ResNet based regression model to predict bounding box coordinates and evaluate performance using the Intersection over Union (IoU) metric. The training loop incorporates learning rate scheduling, loss monitoring, and checkpointing of the best-performing model. Post training, we visualize predicted bounding boxes and demonstrate transformations that crop and normalize images based on both ground truth and predicted bounding boxes. This work serves as a foundational demonstration of object localization in visual classification tasks.
